# Banking System

## Опис проєкту

Banking System — консольна система управління банківськими рахунками. Застосунок дозволяє створювати клієнтів і рахунки, виконувати фінансові операції та переглядати інформацію про рахунки.

Основна мета системи — надати простий механізм керування банківськими рахунками з перевіркою бізнес-правил та можливістю подальшого розширення функціональності.

## Цільові користувачі

- Банківські оператори
- Адміністратори системи
- Навчальні користувачі для демонстрації банківських процесів

## Основні сценарії використання

### UC-1. Створення банківського рахунку

Користувач створює нового клієнта та відкриває для нього рахунок.

### UC-2. Поповнення рахунку

Користувач вносить кошти на існуючий рахунок. Система перевіряє коректність суми та оновлює баланс.

### UC-3. Переказ між рахунками

Користувач виконує переказ коштів між двома рахунками. Система перевіряє наявність достатнього балансу та фіксує транзакцію.

## Нефункціональні вимоги

1. Код повинен відповідати принципам SOLID.
2. Система повинна бути придатною до модульного тестування.
3. Архітектура повинна дозволяти легко замінити In-Memory сховище на файлове або інше джерело даних.
4. Помилки повинні оброблятися контрольованим способом без аварійного завершення роботи програми.
5. Проєкт повинен підтримувати поетапне розширення функціональності.

## Обмеження ітерації 1

На першій ітерації не реалізуються:

- Збереження даних у файл.
- Перекази між рахунками.
- Пошук та аналітичні запити через LINQ.
- Ролі користувачів та авторизація.
- Інтеграційні тести.
- Повноцінна історія транзакцій.

## Межі системи

Перша ітерація охоплює лише сценарій:

Створення рахунку → Поповнення рахунку → Перегляд балансу.

Саме цей сценарій буде реалізований як перший вертикальний зріз через усі шари системи.
