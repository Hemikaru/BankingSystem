# Release Plan v1.0.0

## Scope of Release

Version 1.0.0 includes:

- Account creation
- Deposit operations
- Withdraw operations
- Transfer operations
- JSON persistence
- Account restoration from file
- LINQ analytics
- Automated testing
- Integration testing
- CI quality gate

---

## Deferred Features

The following improvements are intentionally postponed beyond the course scope:

- Database integration
- Concurrent transaction handling
- User authentication
- Account history reports
- Interest calculation for savings accounts
- External banking APIs

---

## Accepted Technical Debt

The following limitations are acceptable for v1.0.0:

- File-based persistence instead of a database
- Limited console UI validation
- No transaction rollback mechanism
- No concurrent access support
