# Banking System

## Опис проєкту

Banking System — навчальний консольний застосунок для управління банківськими рахунками, створений у межах курсу об'єктно-орієнтованого програмування.

Проєкт розробляється ітеративно та демонструє використання принципів ООП, SOLID, шаблонів проєктування, тестування та роботи з файлами.

---

## Реалізована функціональність

### Управління рахунками

- Створення рахунку
- Підтримка декількох типів рахунків
- Перегляд балансу

### Фінансові операції

- Поповнення рахунку
- Зняття коштів
- Переказ між рахунками

### Збереження даних

- Збереження стану у JSON-файл
- Відновлення стану із JSON-файлу
- Асинхронний файловий ввід/вивід

### Аналітика

- Пошук рахунків із позитивним балансом
- Сортування рахунків за балансом
- Пошук рахунку з найбільшим балансом
- Розрахунок загального балансу системи

---

## Бізнес-правила

- Сума поповнення повинна бути більшою за нуль.
- Сума зняття повинна бути більшою за нуль.
- Баланс рахунку не може бути від'ємним.
- Неможливо переказати кошти самому собі.
- Неможливо переказати більше коштів, ніж доступно на рахунку.

---

## Архітектура

Проєкт поділений на декілька шарів.

```text
src/
├── BankingSystem.Domain
├── BankingSystem.Application
├── BankingSystem.Infrastructure
└── BankingSystem.Console
```

### Domain

Містить:

- сутності;
- перерахування;
- інтерфейси репозиторіїв;
- бізнес-інваріанти.

### Application

Містить:

- сервіси;
- DTO;
- фабрики;
- контракти для persistence.

### Infrastructure

Містить:

- репозиторії;
- JSON persistence;
- файлове збереження.

### Console

Містить користувацький інтерфейс та меню.

---

## Використані патерни

### Repository Pattern

Використовується для ізоляції доступу до даних.

### Factory Pattern

Використовується для створення різних типів рахунків без зміни сервісів.
